# Geoffrey Lew — Field notes

Engineering essays on data, AI, and automation, with runnable companion repositories.

Edit the Markdown in `posts/`, then run `npm ci` and `npm run build`. Commit the generated HTML with the source. To preview, run `python3 -m http.server 8000` from this directory.

The site is static HTML and CSS. Marked converts the Markdown articles into HTML at build time. Fonts load from Google Fonts, with system fallbacks.

For GitHub Pages, select **Deploy from a branch**, `main`, and `/ (root)` in the repository's Pages settings.
