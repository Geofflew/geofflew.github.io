# Geoffrey Lew — Field notes

Engineering essays on data, AI, and automation, with runnable companion repositories.

**[Read the blog →](https://geofflew.github.io/)**

Each article has a **Read Markdown** link to `/<article-slug>/index.md`.
These plain-text editions include the canonical article URL, image descriptions,
and absolute image links; they do not require JavaScript.

Edit article content in `posts/*.md`, then run `npm ci && npm run build` to
regenerate both HTML and Markdown. Commit the generated files with the sources:
GitHub Pages serves the checked-in static files directly (`.nojekyll`).
Run `node --test test/markdown.test.mjs` to check the Markdown conversion.
